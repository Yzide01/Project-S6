# Chromesthesia

This folder contains the source code of our game.

## How to run

The game was made using the Godot Game Engine.

You can open the project on Godot by choosing the file project.godot to import the game.

## Structure of the code

/addons: plugins used\
/Assets: The different audio/visual assets of the game\
/Core: Some core mechanics implementation\
/Dialogues: The different dialogues of the game\
/Entities: Related to the player, ennemies...\
/Interactables: Interaction implementation\
/Items: Different items of the game\
/Levels: Implementation of the levels\
/Scenes: Different utility scenes

## Controls

You can take a look at the commands in the menu (ESC)

WASD: classic keybinds to move around the map\
Q: use the selected inventory object\
E: Interact\
Space: Jump\
Enter/click: Skip dialogue\
ESC: Skip cinematic\
Mouse scroll: Change inventory selection
